# lazymidi 0.1.8

Piano sheet music from MIDI, with playback and in-app Converter setup.

## Changes

- Library cards have one **Sheet** button. The shared viewer switches between
  **QWERTY** game keys and **Piano** notation. **Settings → Modules → Show Piano
  button** controls whether Piano is available.
- Compact playback controls, click-to-seek on notes and bars, track selection,
  rhythm detail and zoom. The cursor follows the music without the backward
  jumps seen in Chicago_1. Follow leaves room above high notes and beams;
  manual scrolling turns it off.
- Clearer notation for separate hands, chords, intentional rests and mixed
  rhythms, including Fantaisie-Impromptu's sixteenths against triplets.
  Playback keeps the original performance and source MIDI files stay unchanged.
- Piano and Visualizer share the selected SoundFont and keep it loaded when
  switching songs or reopening a viewer. Opening or playing another viewer
  stops the previous player.
- Clearing Library search restores the page you were browsing. Sheet, Export
  and delete stay aligned when resizing, with denser cards and tidier controls.
- Runtime setup installs Python, the piano model and notation dependencies
  from inside the app, with progress, cancellation and retry. Each installation
  checks conversion and Piano before activation.
- The README describes the app without embedded release history.

## Install or upgrade

On Windows, use the installer or extract the **entire portable ZIP**, keeping
`_up_` beside `lazymidi.exe`. The portable ZIP also includes the optional browser
extension. The separate `lazymidi.exe` is for replacing the executable in an
existing complete 0.1.8 folder.

Enable **Converter** in Settings, then open **Convert → Runtime setup → Install
Converter**. Existing users can choose **Update Converter** to get music21 9.7.1
and the current dependencies. Existing environments are under **Advanced setup**.

CPU setup supports Windows x64, Linux x64, and both Mac architectures.
Windows/Linux also offer NVIDIA GPU setup. Apple GPU processing is enabled
when its local conversion check passes. Dependencies download only when needed;
there are no separate Python/model packs to assemble.

For the browser extension, extract its ZIP, load the `extension/` folder as an
unpacked Chrome/Edge extension, and keep lazymidi running with Converter enabled.
Reload an existing unpacked extension and refresh supported pages after updating.

## Downloads

- Windows: `lazymidi_0.1.8_x64-setup.exe` or `lazymidi_0.1.8_windows-x64-portable.zip`
- Linux x64: `lazymidi_0.1.8_amd64.deb` or `lazymidi_0.1.8_amd64.AppImage`
- macOS 14+: `lazymidi_0.1.8_aarch64.dmg` (Apple Silicon) or `lazymidi_0.1.8_x86_64.dmg` (Intel)
- Browser extension: `lazymidi_0.1.8_converter-extension.zip`
- File checksums: `SHA256SUMS.txt`

Windows builds are unsigned; Mac apps are ad-hoc signed and not notarized.
Linux/macOS remain experimental, with physical MIDI/Wooting hardware and OS
permissions still requiring manual qualification. Install the Wooting SDK
separately for analog input. Automatically generated notation may need editing
for freely timed performances or dense arrangements.
