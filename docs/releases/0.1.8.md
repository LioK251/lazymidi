# lazymidi 0.1.8

Piano sheet music from MIDI, alongside the existing game key sheets.

- Library cards have **Sheet**, **Export** and **×** on one row. The floating
  Sheet viewer switches between **QWERTY** and **Piano** notation.
- **Show Piano button** in Settings → Modules is on by default. Turn it off
  to hide Piano in Convert and the floating viewer. Library density stays the same.
- Piano includes compact playback controls, click-to-seek on notes and bars, and a following cursor
  that stays the same width at any zoom, plus track selection and rhythm detail.
  Follow includes high notes and beams with space above them; manual scrolling turns it off. Closing, minimizing or
  replacing the score pauses playback. Opening or playing another viewer stops
  the previous player.
- Piano and Visualizer share the selected SoundFont. Both viewers retain their
  loaded font when closed, and switching sheets or songs keeps it loaded.
- Clearing Library search returns to the page you were browsing. Search results
  have separate pagination; deleting files keeps the saved page within bounds.
- Settings controls are aligned and grouped. Headings, song actions and controls
  wrap in smaller windows; the library search keeps its width.
- Song-card delete buttons stay aligned beside Sheet and Export when resizing.
- The README describes the current app without embedded release history.
- Cleaner chords, staccato notation, key signatures and rhythm estimation for
  recorded performances. Fixed stray tuplets and backward cursor jumps, checked
  with **Abyss - Kaiju No. 8 OP | Piano | YUNGBLUD**. Working appears beside Piano.
- Separate piano tracks keep their hand assignment across middle C. Triplets
  and straight rhythms can play together on different staves, as in
  **Fantaisie-Impromptu**. Nearly simultaneous chord notes and overlapping voice
  rests are cleaned up, including **Queen – Bohemian Rhapsody (Piano Cover)**.
- The playback cursor follows shared rhythmic columns through rests and mixed
  tuplets, fixing backward jumps in **Chicago_1**, especially bars 2–5.
  Clicking a note seeks to that note even in tightly spaced passages.
- Authored sixteenth rests and full-beat beams are preserved in
  **Fantaisie-Impromptu**. Left-hand triplets keep their eighth-note beams and
  visible numbers; short chromatic neighbours use clearer accidentals.
- Runtime setup installs dependencies inside the lightweight app, with progress,
  cancellation and retry. No separate Python/model packs are needed.
  Each installation checks actual conversion and Piano before activation.
  Failed setup preserves the previous runtime and active conversions.

## Upgrade

Open **Convert → Runtime setup → Update Converter** to install the complete
runtime, including music21 9.7.1. New users choose **Install Converter**.
Existing environments remain available under Advanced setup; **Check again**
rechecks the selected environment without another folder selection.

CPU setup is available for Windows x64, Linux x64 and both Mac architectures.
Windows and Linux also offer NVIDIA GPU setup. Apple GPU support is enabled
only when the local model check succeeds. Saved GPU preferences fall back to
CPU when unavailable and are retained for later use.

MIDI notation is generated automatically. Freely timed performances and dense
arrangements may need editing in a notation program. Original MIDI files remain
unchanged, and playback retains selected tracks' original timing and controllers.

Extract the complete portable ZIP and keep `_up_` beside `lazymidi.exe`.
Windows builds are unsigned; Mac apps are ad-hoc signed and not notarized.
Install Converter from inside the app; Python and model dependencies are
downloaded only when needed. Install the Wooting SDK separately for analog input.
Dependency licenses are retained, with [matching FFmpeg, OpenSSL and LAME
sources](https://lazymidi.vercel.app/third-party/) and bundled build instructions.

Validation and platform limits are recorded in [testing](https://github.com/LioK251/lazymidi/blob/v0.1.8/docs/testing.md).
