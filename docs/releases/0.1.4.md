# lazymidi 0.1.4

Optional tools for virtual piano players, with the existing analog and MIDI output paths kept independent.

## Added

- Discord Rich Presence with connected input labels and a configurable GitHub Get button. Both settings default On; Discord is optional.
- Game-control Transposer with saved sequences/bindings, global performance shortcuts and a compact floating monitor. Tracking starts at 0 and follows completed key pulses. Start the game's transpose at 0; direct in-game changes cannot be detected.
- Optional converter using an existing compatible Python/Transkun/FFmpeg environment. Environment validation avoids installing a second CUDA stack. Separate copy-only import preserves the original converter's data.
- Converter library cards, immediate sheet generation, Auto/Multi/Manual/Original sheet modes, BPM/timing visibility controls and synchronized floating sheets.
- Send to Transposer replaces the sequence with the displayed headings, preserving signs and duplicates. When Transposer is enabled and bindings are configured, it automatically resumes and applies the first target.
- Separate piano visualizer window, `.sf2` selection/import, style previews, hand editing/exports and video rendering. Loaded SoundFonts are reused across songs and window closes until the app exits.
- Optional paired Chromium extension for supported media links and user-provided MIDI imports.

## Fixed and polished

- Consistent custom title bars across the main window, monitor, sheets and visualizer.
- Native floating-window startup and visualizer reopen handling.
- Stale sheet/visualizer results, scoped media reads, bounded SoundFont transfers and recoverable converter data import.
- More responsive transpose delivery with completed-pulse accounting and cancellation cleanup.
- Removed manual Sync/Resume controls from the main Transposer page, redundant sheet notifications and click-through controls. Visualizer appearance settings sit below the player; Stay on top is aligned with its label.
- Opening or reopening the monitor automatically resumes with configured bindings. The monitor is 260 × 130 without a scrollbar; sequence sending preserves musical input switches. The Sequencer tab remains hidden.

## Downloads and upgrade

Windows 11 x64:

- `lazymidi_0.1.4_x64-setup.exe`: current-user installer.
- `lazymidi_0.1.4_windows-x64-portable.zip`: extract everything, then run `lazymidi.exe`. Keep `_up_` beside it for converter service resources.
- `lazymidi.exe`: executable only; converter resources require the portable ZIP or installer.
- `lazymidi_0.1.4_converter-extension.zip`: extract, then load `extension/` as an unpacked Chromium extension.
- `SHA256SUMS.txt`: SHA-256 checksums for release assets.

Close the previous version before starting the new one. Profiles/settings retain their existing app-data locations and are not reset by this upgrade. New optional settings load with backward-compatible defaults. Wooting's SDK remains separately installed and is loaded only when Analog is enabled.

## Limits

- Builds are unsigned. Linux/macOS source adapters are present; installers and native hardware qualification are not included.
- **Converter runtime downloads are not available.** Use an existing compatible environment. CPU/CUDA runtime packs are excluded pending redistribution/source verification; no model, FFmpeg, songs, SoundFonts, cookies or user history ship in these assets.
- Live Discord lifecycle, Roblox reception of rapid transpose pulses, fullscreen/DPI focus behavior and online media-site workflows still need manual qualification. No claim of improved audible Roblox latency is made.
- The game exposes no transpose telemetry: tracking assumes 0 on launch/recovery. After interrupted delivery, reset the game to 0 before resuming.
