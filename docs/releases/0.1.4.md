# lazymidi 0.1.4

Optional tools for virtual piano players, with compact floating windows and sheet fixes.

## Added

- Optional Discord Rich Presence with input labels and a configurable GitHub Get button.
- Game-control Transposer with saved sequences/bindings, global shortcuts and a compact 260 × 130 monitor. Opening the monitor or sending a sheet sequence resumes output when bindings are configured.
- Optional converter using an existing Python/Transkun/FFmpeg environment, copy-only library import and a paired Chromium extension.
- Immediate sheet generation, Auto/Multi/Manual/Original modes, floating sheets and a separate piano visualizer with reusable SoundFonts, style controls and exports.

## Fixed and polished

- Accept transpose headings with relative-change annotations, such as `Transpose by: -3 (-7)`. Previously these produced "A transpose heading contains an invalid value."
- Send absolute game targets in their displayed order, preserving signs and repeated values. The parenthesized change is informational and is not sent as another target.
- Retain malformed-heading rejection and the existing sequence length/range checks. Auto and Manual headings use the same corrected reader.
- Group sheet opacity, Stay on top, colors, centering and zoom under View; keep the main sheet actions and mode selector visible.
- Keep Manual-mode headings and point controls aligned to the normal sheet line spacing.
- Update an already-open floating sheet without switching the main converter tab to Sheets.
- Share the main app's title bar across floating windows and retain SoundFonts across songs and visualizer closes until app exit. Sequencer navigation remains hidden.

## Downloads and upgrade

- `lazymidi_0.1.4_x64-setup.exe`: Windows x64 installer.
- `lazymidi_0.1.4_windows-x64-portable.zip`: extract everything and run `lazymidi.exe`; keep `_up_` beside it.
- `lazymidi.exe`: executable only; use the installer or portable ZIP for converter resources.
- `lazymidi_0.1.4_converter-extension.zip`: unpacked Chromium extension.
- `SHA256SUMS.txt`: release asset checksums.

Close the previous version before upgrading. Existing profiles, converter settings and data are preserved.

Windows builds remain unsigned. Converter runtime downloads remain unavailable; existing compatible environments are supported. Live Roblox reception of transpose pulses is not qualified by this parser fix.

See the [README](../../README.md) and [optional modules](../optional-modules.md) for platform limitations. Transposer tracking assumes the game's initial value is 0; direct in-game changes cannot be detected. Live Discord, fullscreen/DPI behavior and non-Windows native features still need manual qualification.
