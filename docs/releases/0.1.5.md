# lazymidi 0.1.5

Converter workflow, browser integration and sheet-window fixes for virtual piano players.

## Changes

- Add **Always open Float** in Convert → Sheets, default Off. When enabled, every Sheet action opens the floating viewer and keeps the current converter section. This preference saves immediately.
- Restore a minimized sheet viewer when pressing Sheet or Float sheet, without redirecting to the main Sheets tab.
- Remember sheet opacity, zoom, Colors, Center and Stay on top across window closes and application restarts.
- Save floating-window geometry periodically and on close; preserve normal dimensions while maximized, skip minimized sizes, scale restored sizes for DPI and recover invalid geometry from its backup.
- Allow all converter fields to receive MIDI → QWERTY typing, including analog input when normal digital keys are disabled in Wootility. Musical mapping editors and dialogs retain their generated-key pause.
- Place **Cancel** beside **Convert link** while a link job runs; retain cancellation for local files.
- Save the selected compute device immediately and restore it across launches. Browser conversions use the same preference; unavailable CUDA falls back to CPU without forgetting it.
- Add **Convert with lazymidi** to the right-click menu for Discord browser audio/video attachments, preserving signed attachment URLs. Retain YouTube/TikTok page controls and downloaded MuseScore MIDI import.
- Show browser conversion status/errors in the extension popup and refresh the Library when returning to lazymidi or Convert.
- Remove manual browser pairing. Discover the converter automatically, reconnect after app restarts and keep supported-page buttons visible before connection. Add controls to already-open supported tabs on installation.
- Prepare the lightweight converter service while Converter is enabled, even when its tab is not selected; model inference still loads only for a job.
- Isolate settings and converter data during packaged native smoke tests.

## Downloads and upgrade

- `lazymidi_0.1.5_x64-setup.exe`: Windows x64 installer.
- `lazymidi_0.1.5_windows-x64-portable.zip`: extract everything and run `lazymidi.exe`; keep `_up_` beside it.
- `lazymidi.exe`: executable only; use the installer or portable ZIP for converter resources.
- `lazymidi_0.1.5_converter-extension.zip`: unpacked Chromium extension, also included in the portable ZIP.
- `SHA256SUMS.txt`: release asset checksums.

Close the previous version before upgrading. Existing profiles, converter data and compatible Python environments are preserved. Set the sheet view preferences once in this version; earlier versions did not persist them.

## Verification and limitations

107 frontend/extension tests, 54 Rust checks, 45 SDK-free core checks and 18 private-service tests pass; one optional inference test is skipped. TypeScript/Vite, formatting and Clippy pass. Packaged Windows checks cover native startup, floating windows, minimizing/restoring the sheet, converter service, sheet generation and visualizer loading with isolated data. No SDK initialization or keyboard injection is enabled during smoke tests.

Windows builds are unsigned. Live website downloads, hardware typing, Roblox/fullscreen behavior and multi-monitor/DPI transitions still require manual qualification. Linux/macOS packages and converter runtime packs are not included; existing compatible converter environments remain supported.

This replacement supersedes the withdrawn 0.1.5 build and removes the 0.1.6 release. Replace the older unpacked extension after updating; connection is automatic. See the [README](../../README.md) and [optional modules](../optional-modules.md) for setup and platform limitations.
