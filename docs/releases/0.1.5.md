# lazymidi 0.1.5

Converter workflow, browser integration and sheet-window fixes for virtual piano players, with experimental Mac installers.

## Changes

- Add **Always open Float** in Convert → Sheets, default Off. When enabled, every Sheet action opens the floating viewer and keeps the current converter section. This preference saves immediately.
- Restore a minimized sheet viewer when pressing Sheet or Float sheet, without redirecting to the main Sheets tab.
- Remember sheet opacity, zoom, Colors, Center and Stay on top across window closes and application restarts.
- Save floating-window geometry periodically and on close; preserve normal dimensions while maximized, skip minimized sizes, scale restored sizes for DPI and recover invalid geometry from its backup.
- Allow all converter fields to receive MIDI → QWERTY typing, including analog input when normal digital keys are disabled in Wootility. Musical mapping editors and dialogs retain their generated-key pause.
- Place **Cancel** beside **Convert link** while a link job runs; retain cancellation for local files.
- Save the selected compute device immediately and restore it across launches. Browser conversions use the same preference; unavailable CUDA falls back to CPU without forgetting it.
- Add **Convert with lazymidi** to the right-click menu for Discord browser audio/video attachments, preserving signed attachment URLs. Retain YouTube/TikTok page controls.
- Replace the existing MuseScore file picker with **Download MIDI to lazymidi**, using LibreScore's dynamic MD5 authorization and legacy fallback. Downloads use restricted CDN hosts, size limits and the authenticated MIDI import; no extra button or manual pairing is required. Include upstream MIT notices and the MD5 helper's license.
- Show browser conversion status/errors in the extension popup and refresh the Library when returning to lazymidi or Convert.
- Remove manual browser pairing. Discover the converter automatically, reconnect after app restarts and keep supported-page buttons visible before connection. Add controls to already-open supported tabs on installation.
- Prepare the lightweight converter service while Converter is enabled, even when its tab is not selected; model inference still loads only for a job.
- Isolate settings and converter data during packaged native smoke tests.
- Add native macOS Apple Silicon and Intel builds with verified DMG integrity, app architecture, resources and SDK-free frontend startup.

## Downloads and upgrade

- `lazymidi_0.1.5_x64-setup.exe`: Windows x64 installer.
- `lazymidi_0.1.5_windows-x64-portable.zip`: extract everything and run `lazymidi.exe`; keep `_up_` beside it.
- `lazymidi.exe`: executable only; use the installer or portable ZIP for converter resources.
- `lazymidi_0.1.5_converter-extension.zip`: unpacked Chromium extension, also included in the portable ZIP.
- `lazymidi_0.1.5_aarch64.dmg`: experimental macOS 14+ Apple Silicon installer.
- `lazymidi_0.1.5_x86_64.dmg`: experimental macOS 14+ Intel installer.
- `SHA256SUMS.txt`: release asset checksums.

Close the previous version before upgrading. Existing profiles, converter data and compatible Python environments are preserved. Set the sheet view preferences once in this version; earlier versions did not persist them.

## Verification and limitations

118 frontend/extension tests, 54 Windows Rust checks, 45 SDK-free core checks and 18 private-service tests pass; one optional inference test is skipped. TypeScript/Vite, formatting and Clippy pass. Packaged Windows checks cover native startup, floating windows, minimizing/restoring the sheet, converter service, sheet generation and visualizer loading with isolated data. Mac checks run on both native architectures and launch each app from its mounted DMG. No SDK initialization or keyboard injection is enabled during smoke tests.

Windows builds are unsigned. Mac apps use ad-hoc signatures and are **not Apple notarized**; macOS may block first launch. Actual Mac MIDI/Wooting hardware, Accessibility permissions, Roblox, audio and converter environments remain unqualified. Live MuseScore testing of the supplied score was blocked by Cloudflare verification; native-player token interception is not implemented, and successful live downloading is not claimed. Other live website downloads, hardware typing, fullscreen behavior and multi-monitor/DPI transitions still require manual qualification. Linux installers and converter runtime packs are not included; existing compatible Windows converter environments remain supported.

This replacement includes all current changes and supersedes earlier 0.1.5 downloads. The 0.1.6 release remains withdrawn. Replace the older unpacked extension after updating; connection is automatic. See the [README](../../README.md) and [optional modules](../optional-modules.md) for setup and platform limitations.
