# lazymidi 0.1.6

Keep your place in the MIDI library when opening sheets.

## Changes

- Fix the library resetting to page one after **Sheet**, returning from the floating viewer, or refreshing the library. Preserve the current page when refreshed files still fit it.
- Reset pagination for a new search. When deletion removes the current page, move to the last remaining page without jumping back again when more files arrive.
- Keep existing sheet generation, **Always open Float**, minimized-window restoration and converter settings unchanged.
- Include the current MuseScore/LibreScore browser extension and all previous 0.1.5 features.

## Downloads and upgrade

- `lazymidi_0.1.6_x64-setup.exe`: Windows x64 current-user installer.
- `lazymidi_0.1.6_windows-x64-portable.zip`: extract everything and run `lazymidi.exe`; keep `_up_` beside it. Includes the browser extension and documentation.
- `lazymidi.exe`: executable only; prefer the installer or portable ZIP for converter resources.
- `lazymidi_0.1.6_aarch64.dmg`: experimental macOS 14+ Apple Silicon installer.
- `lazymidi_0.1.6_x86_64.dmg`: experimental macOS 14+ Intel installer.
- `lazymidi_0.1.6_converter-extension.zip`: unpacked Chromium extension. Replace any older unpacked copy, then reload supported pages.
- `SHA256SUMS.txt`: checksums for the downloads and license notices.

Close the older app before upgrading. Profiles, converter data, imported SoundFonts and existing compatible Python environments are preserved. No Wooting SDK, Python/model runtime or CUDA pack is bundled.

## Verification and limitations

121 frontend/extension tests pass, including Sheet → focus refresh in both normal and Always open Float modes, deletion/page clamping and new-search resets. Release checks cover native Rust, SDK-free operation, Python service/environment tests, formatting, Clippy and packaged startup. Mac DMGs are built and checked on their respective native architectures, including launching the app from the mounted image.

Windows builds are unsigned. Mac apps have ad-hoc signatures and are **not notarized**; macOS may block first launch. Actual Mac MIDI/Wooting hardware, Accessibility permissions, Roblox, audio and converter environments remain unqualified. Live MuseScore downloading was blocked by Cloudflare during previous testing; native-player token interception remains excluded. Hardware playing, fullscreen/DPI behavior and live website downloads still need manual qualification.

See the [README](../../README.md) and [optional modules](../optional-modules.md) for setup. Linux installers and converter runtime packs remain unavailable.
