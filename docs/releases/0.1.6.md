# lazymidi 0.1.6

Sheet-window persistence and navigation fixes for virtual piano players.

## Changes

- Add **Always open Float** in Convert → Sheets, default Off. When enabled, every Sheet action opens the floating viewer and keeps the current converter section. This preference saves immediately.
- Restore a minimized sheet viewer when pressing Sheet or Float sheet, without redirecting to the main Sheets tab.
- Remember sheet opacity, zoom, Colors, Center and Stay on top across window closes and application restarts.
- Save floating-window geometry periodically and on close; preserve normal dimensions while maximized, skip minimized sizes, scale restored sizes for DPI and recover invalid geometry from its backup.
- Allow converter Library search to receive MIDI → QWERTY typing, including analog input when normal digital keys are disabled in Wootility. Other editors and dialogs retain their generated-key pause.
- Isolate settings and converter data during packaged native smoke tests.

## Downloads and upgrade

- `lazymidi_0.1.6_x64-setup.exe`: Windows x64 installer.
- `lazymidi_0.1.6_windows-x64-portable.zip`: extract everything and run `lazymidi.exe`; keep `_up_` beside it.
- `lazymidi.exe`: executable only; use the installer or portable ZIP for converter resources.
- `lazymidi_0.1.6_converter-extension.zip`: unpacked Chromium extension, also included in the portable ZIP.
- `SHA256SUMS.txt`: release asset checksums.

Close the previous version before upgrading. Existing profiles, converter data and compatible Python environments are preserved. Set the sheet view preferences once in this version; earlier versions did not persist them.

## Verification and limitations

81 frontend tests, 54 Rust checks, 45 SDK-free core checks, TypeScript/Vite, formatting and Clippy pass. Packaged Windows checks cover native startup, floating windows, minimizing/restoring the sheet, converter service, sheet generation and visualizer loading with isolated data. No SDK initialization or keyboard injection is enabled during smoke tests.

Windows builds are unsigned. Live hardware typing, Roblox/fullscreen behavior and multi-monitor/DPI transitions still require manual qualification. Linux/macOS packages and converter runtime packs are not included; existing compatible converter environments remain supported.

Version 0.1.5 was withdrawn; its existing tag is retained. See the [README](../../README.md) and [optional modules](../optional-modules.md) for setup and platform limitations.
