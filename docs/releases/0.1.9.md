# lazymidi 0.1.9

Piano notation fixes, MusicXML/PDF export, and Float monitor shortcut control.

## Changes

- Fixed Piano's `minimumStaffEntriesWidth` crash on silent measures in
  **Glimpse of Us - Joji (Piano Cover)**. Failed layouts no longer report success,
  and successful redraws clear old errors.
- Fixed another Glimpse cover failing in Detailed mode when splitting a chord
  left a note length that could not be exported. Ties preserve its duration.
- Clearer piano engraving: sustained register changes use suitable clefs,
  and continuous eighth-triplet accompaniment in 4/4 uses six-note beams.
- Piano's **Tracks & rhythm**, **Export** and **View** menus close the previous
  menu when opened. **Follow** sits after **Export**. The track explanation and
  separate song heading have been removed to leave more room for notation.
- The sheet title bar shows **Piano · Song name** or **QWERTY · Song name**.
  Long names fit without hiding the window controls.
- **Piano → Export** saves MusicXML or opens **Print / Save PDF** with A4 pages,
  a centered song title and **lazymidi** credit. Long titles wrap. Playback and
  source MIDI files retain their original pitches, timing and contents.
- Both exports pause playback and wait for audio suspension before preparing
  the score or opening a dialog, preventing a sustained note during export.
  Play resumes from the saved position after exporting or cancelling.
- PDF exports suggest the song name, matching MusicXML exports, instead of
  saving as `lazymidi.pdf`.
- Transposer shortcuts register only while Float monitor is visible and not
  minimized. Closing or minimizing pauses Transposer and cancels pending output.
  Reopening leaves it paused until Resume.

## Install or upgrade

Use `lazymidi_0.1.9_x64-setup.exe`, or extract the entire
`lazymidi_0.1.9_windows-x64-portable.zip`. Keep `_up_` beside `lazymidi.exe`;
it contains the Converter code and runtime tools. The portable ZIP also includes
the browser extension. No Converter runtime reinstall is needed for these fixes
if music21 9.7.1 is already available.

Use the installer or complete portable ZIP when upgrading from 0.1.8, because
the bundled Converter code also changed. The separate `lazymidi.exe` is only for
replacing the executable in an existing complete 0.1.9 folder.

For the browser extension, extract its ZIP and load the `extension/` folder as
an unpacked Chrome/Edge extension. Reload an existing unpacked extension and
refresh supported pages after updating.

## Downloads

- Windows: `lazymidi_0.1.9_x64-setup.exe` or `lazymidi_0.1.9_windows-x64-portable.zip`
- Linux x64: `lazymidi_0.1.9_amd64.deb` or `lazymidi_0.1.9_amd64.AppImage`
- macOS 14+: `lazymidi_0.1.9_aarch64.dmg` (Apple Silicon) or `lazymidi_0.1.9_x86_64.dmg` (Intel)
- Browser extension: `lazymidi_0.1.9_converter-extension.zip`
- File checksums: `SHA256SUMS.txt`

Windows builds are unsigned; Mac apps are ad-hoc signed and not notarized.
Linux/macOS remain experimental. Physical MIDI/Wooting hardware, game input
and OS permissions require separate manual qualification. Install the Wooting
SDK separately for analog input.

MIDI does not contain the original score's complete phrasing, dynamics or page
layout. Automatic notation can need correction in a notation editor.
